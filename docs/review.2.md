# Review

Существенных замечаний к изменению нет. Cisco-target использует один выбранный control-DTB, сохраняет RAM text base `0x84000000`, совпадает со скоростью штатной консоли 9600 бод и не включает постоянное хранилище окружения. Аппаратный запуск остаётся единственной проверкой поведения после `go`.
