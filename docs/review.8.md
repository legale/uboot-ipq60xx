# Review

Существенных блокирующих замечаний по сетевому исправлению не выявлено.

Проверено:

- Cisco Ethernet инициализируется только при явной сетевой команде, поэтому старт до prompt остаётся безопасным;
- PSGMII self-test и повторный reset PHY исключены только для Cisco chainload target, поскольку PHY уже подготовлен штатным BTLDR;
- чтение MAC из ART не заменено hardcode; исправлено только отображение с `%02x`, чтобы `0x0a` не выглядел как `a`;
- raw BIN успешно собран и скопирован в TFTP.

Ограничение: передачу TFTP и link state необходимо подтвердить на плате.
