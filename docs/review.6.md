# Review

Существенных блокирующих замечаний по последнему исправлению нет.

Проверено:

- `dram_init()` при `CONFIG_CISCO_AP1800S` не использует stale SMEM RAM table и берёт размер из `ddr_size` DTS;
- crashdump/dload путь отключён только для Cisco target, при этом общие target'ы его не теряют;
- для Cisco окружение остаётся RAM-only, а увеличение буфера не добавляет записи во flash;
- raw BIN начинается с векторов, содержащих адреса `0x84000000`;
- сборка `u-boot.bin` завершилась успешно.

Ограничение проверки: фактическое прохождение prompt и отсутствие зависания на конкретной плате требуют аппаратного запуска через BTLDR; статически это не подтверждается.
